# Security policy

## Supported releases

Security fixes are applied to the latest published release of Tomorrow Now PDF
Editor. Users should install updates from the official GitHub Releases page.

## Reporting a vulnerability

Please do not publish an exploitable vulnerability in a public issue. Report it
privately to `security@tomorrownow.tech` with the affected version, steps to
reproduce and any relevant sample file stripped of personal data.

The application is designed to process PDFs locally. A report that shows an
unexpected network transfer or access to unrelated local files is considered
high priority.
